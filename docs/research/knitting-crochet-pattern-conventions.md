# Knitting & Crochet Pattern Conventions

A research report on how knitting and crochet patterns are typically described, with a focus on structure, terminology, beginner conventions, and temperature blanket specifics.

---

## 1. Pattern Structure

### Standard Section Order

Nearly all published patterns — whether from Vogue Knitting, Lion Brand, Ravelry designers, or Drops Design — follow a consistent section order. Multiple beginner guides confirm the same structure:

1. **Pattern Name & Designer**
2. **Description / Overview** (skill level, finished size, construction notes)
3. **Materials / Supplies** (yarn type, weight, quantity, needle/hook size, notions)
4. **Gauge / Tension**
5. **Abbreviations / Glossary**
6. **Finished Measurements / Sizing**
7. **Stitch Guide / Special Stitches** (if applicable)
8. **Pattern Instructions** (row-by-row or round-by-round)
9. **Finishing** (weaving in ends, blocking, seaming)

- [AKARI Notes: Beginner's Guide to Reading a Knitting Pattern](https://akarinotes.com/2025/05/24/beginners-guide-to-reading-a-knitting-pattern/) — Lists sections as: Pattern Name & Designer, Materials, Gauge (Tension), Sizes & Measurements, Abbreviations, Instructions, Finishing
- [Just Be Crafty: How to Read Knitting Patterns](https://justbcrafty.com/how-to-read-knitting-patterns-a-comprehensive-beginners-guide/) — Lists: Materials List, Abbreviations, Gauge, Sizing & Finished Measurements, Step-by-Step Instructions
- [Sheep and Stitch: How to Read a Knitting Pattern](https://sheepandstitch.com/library/how-to-read-a-knitting-pattern-for-beginners-step-by-step-guide/) — Lists: Yarn, Needles, Notions, Gauge, Finished Measurements, Pattern Notes, Instructions, Abbreviations
- [Pattern Princess: How to Read a Crochet Pattern](https://patternprincess.com/how-to-read-a-crochet-pattern-beginner-friendly-guide/) — Lists: Pattern overview, Materials, Abbreviations, Gauge, Step-by-step instructions with notes

### Drops Design Format

DROPS Design (garnstudio.com) patterns are a notable variant — they are translated from Scandinavian originals and use a distinctive format:
- Materials section lists their own yarn brands
- Heavily diagram-based with chart symbols
- Uses "A.1", "A.2" etc. to reference stitch diagrams alongside written instructions
- Metric measurements throughout (centimetres)
- Includes a stitch guide with international crochet symbols

- [CyCrochet: Mastering Drops Crochet Patterns](https://cycrochet.com/article/how-to-read-drops-crochet-patterns) — Describes their structure: schematic, yarn requirements, hook size, stitch guide, diagrams with written instructions, colour changes, assembly instructions
- [KnittingHelp Forum: Drops Design Patterns](https://forum.knittinghelp.com/t/drops-design-patterns/14187) — Users note patterns are "translated" and "not written out as word for word as we are used to"

## 2. Terminology: US vs UK

### The Core Difference

US and UK crochet terminology use the same stitch names but assign them to completely different stitches. The UK system is offset by one step from the US system:

| US Term | UK Term | What's the same |
|---------|---------|----------------|
| Slip stitch (sl st) | Slip stitch (ss) | Same stitch |
| Single crochet (sc) | Double crochet (dc) | Same stitch, different name |
| Half double crochet (hdc) | Half treble (htr) | Same stitch, different name |
| Double crochet (dc) | Treble (tr) | Same stitch, different name |
| Treble (tr) | Double treble (dtr) | Same stitch, different name |
| Double treble (dtr) | Triple treble (trtr) | Same stitch, different name |

**Why they differ:** UK terms count the loops on the hook after pulling up a loop; US terms count the yarn overs before insertion. This is why a US single crochet (zero yarn overs) is a UK double crochet (two loops on hook).

- [Craft Yarn Council: Crochet Abbreviations Master List](https://www.craftyarncouncil.com/standards/crochet-abbreviations) — Official US/UK conversion table
- [KnitPro: UK vs US Crochet Terminology](https://www.knitpro.eu/en/blog/uk-vs-us-crochet-terminology) — Complete conversion chart and explanation of why the systems differ
- [Crochet for Beginners Hub: US vs UK Crochet Terms](https://www.crochetforbeginnershub.com/2026/06/us-vs-uk-crochet-terminology-conversion-guide.html) — Detailed explanation with tips for identifying which system a pattern uses

### How to Tell Which System a Pattern Uses

1. If "sc" (single crochet) appears → US terms (this stitch doesn't exist in UK naming)
2. If "htr" (half treble) appears → UK terms
3. Check whether the pattern says "gauge" (US) or "tension" (UK)
4. Check if it says "skip a stitch" (US) or "miss a stitch" (UK)
5. Check the designer's origin — US/Canada = US terms; UK/Australia/NZ = UK terms

- [Crochet All the Time: US vs UK Crochet Terms](https://crochetallthetime.com/us-vs-uk-crochet-term) — Practical tips for identifying the system
- [Fox Creations: US vs UK Crochet Terminology](https://foxcreations.com.au/amigurumi-101/us-vs-uk-crochet-terminology) — Notes that amigurumi almost always uses US terms

### Knitting Terminology

Knitting terms are largely standardised worldwide. The Craft Yarn Council publishes a master list of knitting abbreviations used by North American designers and publishers. There are minor regional variations (e.g., UK uses "cast off" where US uses "bind off") but the core stitch names (knit, purl) are universal.

- [Craft Yarn Council: Knitting Abbreviations Master List](https://www.craftyarncouncil.com/standards/knitting-abbreviations) — Standard US knitting abbreviations
- [FiberTools: Crochet & Knitting Abbreviations Glossary](https://fibertools.app/abbreviation-glossary) — Notes that knitting stitch names are consistent worldwide

### Knitting vs Crochet Terminology Confusion

A few terms mean different things across the two crafts:
- **sl st (slip stitch):** In knitting, you slip without working; in crochet, you insert hook, pull through loop on hook
- **gauge (US) / tension (UK):** Same concept, different word
- **yo (yarn over) / yoh (yarn over hook):** US vs UK naming for the same action

## 4. How Rows/Instructions Are Written

### Line-by-Line Format

The dominant convention is row-by-row (or round-by-round) written instructions:

**Example (Knitting):**
```
Row 1 (RS): K5, *p2, k2; rep from * to last 5 sts, k5
Row 2 (WS): P5, *k2, p2; rep from * to last 5 sts, p5
```

- **Bold** marks the row number
- (RS) / (WS) indicates which side of the work
- Asterisks (\*) mark repeat boundaries
- Semicolons separate repeat sections from remaining instructions
- "to last X sts" tells you when to stop the repeat

**Example (Crochet):**
```
Row 3: Ch 2, dc in next 10 sts, *2 dc in next st, dc in next 4 sts; rep from * across.
```

- [Make & Do Crew: How to Read Knitting Patterns](https://makeanddocrew.com/read-knitting-patterns/) — Explains the line-by-line structure with examples
- [Secret Yarnery: How to Read Crochet Patterns](https://secretyarnery.com/blogs/blog/how-to-read-crochet-patterns-like-a-pro-beginner-guide-2025) — Breaks down a row instruction step by step

### Multiple Sizes in Brackets

Patterns for garments use bracketed numbers for different sizes:

```
CO 45 (48, 51, 55, 59, 63, 68) sts
```

Each number corresponds to a size listed at the start of the pattern (XS, S, M, L, XL, 2X, 3X).

- [Sheep and Stitch: Understanding Size Instructions](https://sheepandstitch.com/library/how-to-read-a-knitting-pattern-for-beginners-step-by-step-guide/) — Explains bracket notation for multiple sizes

### Charts

Many patterns include visual charts alongside written instructions:
- **Knitting charts:** Grid where each square = one stitch, read right-to-left on RS rows, left-to-right on WS rows
- **Crochet charts:** International symbols (oval = chain, T = treble, etc.) arranged on a grid

DROPS Design is particularly chart-heavy, using "A.1", "A.2" etc. as references to chart sections.

## 5. Colour/Colour-Change Instructions

### In Striped Patterns

Colour changes in stripe patterns are typically described as:

```
Row 15: Ch, sc 11, change to Color B, sc 15, turn.
```

- [Made From Yarn: How to Change Colors in Crochet](https://madefromyarn.com/how-to-change-colors-in-crochet/) — Shows the standard pattern notation: "change to color B"
- [Interweave: Crochet Colorwork — How to Change Yarn Color](https://www.interweave.com/article/crochet/crochet-colorwork-how-to-change-yarn-color/) — Notes to work the last step of a stitch in the new colour for clean transitions

**Key conventions for colour changes:**
- Patterns use **MC (main color)** and **CC (contrasting color)** abbreviations
- Colour changes are stated inline: "change to [color name]" or "with CC, dc across"
- The technique is to complete the last yarn-over of the final stitch in the old colour using the new colour
- For stripes, cutting and rejoining is typical for stripes > 4 rows; carrying yarn up the side works for 1-2 row stripes

- [FiberTools: Yarn Stripe Patterns Guide](https://fibertools.app/guides/yarn-stripe-patterns-guide) — Comprehensive guide on carrying vs cutting, end management, and yardage planning for stripes
- [Nimble Needles: How to Change Colors in Knitting](https://nimble-needles.com/tutorials/how-to-change-colors-in-knitting/) — Six methods for knitting colour changes

### In Temperature Blanket Patterns

Temperature blanket patterns typically describe colour changes via a **colour-temperature key** rather than inline instructions. The pattern provides a table mapping temperature ranges to colour names, and the crafter looks up each day's colour before knitting/crocheting that row.

- [Gabrielle Vézina: How to Knit a Temperature Blanket](https://gabriellevezina.com/knitting-tutorials/miscellaneous/how-to-knit-a-temperature-blanket-or-scarf-tutorial-and-free-knitting-pattern/) — Provides a colour chart: "Dark green: -40°C to -11°C", "Light green: -10°C to -5°C", etc.
- [Noble Knits: Complete Guide to Making Temperature Blankets](https://blog.nobleknits.com/blog/how-to-knit-crochet-temperature-blankets) — Notes that patterns include "a template for the color for temperature"
- [Oombawka Design: Temperature Blankets](https://oombawkadesigncrochet.com/temperature-blankets-crochet-patterns-color-charts-and-tracking-sheets/) — Lists multiple patterns that provide colour charts and tracking sheets

## 6. Gauge/Tension

### What It Is

Gauge (US) / Tension (UK) specifies how many stitches and rows fit into a standard measurement, typically 4 inches (10 cm). It is stated as:

```
Gauge: 20 sts × 28 rows = 10 cm in stockinette stitch
```

### Why It Matters

- Determines finished size — if gauge is wrong, the item won't fit
- Affects yarn usage — tighter gauge uses more yarn per area
- Affects fabric character — too loose sags, too tight is stiff

### How It's Stated

Patterns always specify:
1. The stitch count and row count
2. The measurement (usually 4 inches / 10 cm)
3. The stitch pattern used (e.g., "in stockinette stitch" or "in (k2, p2) ribbing")
4. The needle/hook size used to achieve that gauge

- [AKARI Notes: Why Gauge Matters](https://akarinotes.com/2025/05/24/beginners-guide-to-reading-a-knitting-pattern/) — Explains gauge as "your project's DNA"
- [Just Be Crafty: Gauge and Swatching](https://justbcrafty.com/how-to-read-knitting-patterns-a-comprehensive-beginners-guide/) — "Matching the gauge is essential, particularly for garments or items that require a specific fit"

### UK vs US Naming

| US | UK |
|----|-----|
| Gauge | Tension |
| sts and rows per 4 inches | sts and rows per 10 cm |

- [Craft Yarn Council: US/UK Term Differences](https://www.craftyarncouncil.com/standards/crochet-abbreviations#term-differences) — Official conversion: gauge = tension

## 8. Beginner-Friendly Conventions

### What Makes a Pattern Beginner-Friendly

Based on analysis of multiple beginner pattern guides and designer blogs:

**1. Basic stitches only**
Beginner patterns stick to 5-6 foundational stitches: chain, slip stitch, single crochet, half double crochet, double crochet (and knit, purl for knitting). No complex stitch combinations.

**2. Repetitive stitch patterns**
Simple repeats that let beginners develop rhythm: "sc in next 3 stitches, ch 1, skip 1 stitch." Repetition builds muscle memory and pattern-reading skills.

**3. Clear, explicit instructions**
- Every abbreviation defined
- Full names used alongside abbreviations initially
- Row-by-row guidance with stitch counts
- Helpful notes or tips at tricky points

**4. Simple construction**
- Worked in rows (back and forth) or simple rounds
- Basic rectangles or squares
- Minimal shaping (no complex increases/decreases)
- Little to no sewing or assembly

**5. Forgiving designs**
Small mistakes don't ruin the project. Blankets and scarves are more forgiving than fitted garments.

**6. Photo or video tutorials**
Many beginner patterns include step-by-step photos or links to video tutorials.

- [Sunflower Cottage Crochet: What Makes a Pattern Beginner-Friendly](https://sunflowercottagecrochet.com/easy-crochet-projects-what-makes-a-pattern-beginner-friendly/) — Detailed breakdown of beginner vs intermediate vs advanced patterns
- [My Crochet Space: Crochet Patterns for Beginners](https://mycrochetspace.com/crochet-patterns-for-beginners/) — "The best true beginner patterns use simple stitches, repetitive rows, and minimal shaping"
- [Happy Heartsy: How to Read Crochet Patterns for Beginners](https://www.happyheartsy.com/post/how-to-read-crochet-patterns-for-beginners) — Notes that "many designers have their own way of writing patterns" but standards exist

### Beginner Pattern Language Differences

Beginner patterns tend to:
- Use **full stitch names** alongside abbreviations: "single crochet (sc)"
- Include **plain-English explanations** between abbreviated rows
- Provide **notes and tips** inline (often in italics)
- Use **bold** for row headers to improve scannability
- Include **stitch counts** at the end of each row
- Offer **larger text** and more whitespace in layout

## 9. Temperature Blanket Specifics

### How Temperature Blanket Patterns Are Structured

Temperature blanket patterns are distinct from typical garment or accessory patterns. They combine a standard pattern structure with a **data-driven colour selection** component.

**Typical structure:**

1. **Introduction / Concept** — Explains the idea (one row per day, colour = temperature)
2. **Temperature Data** — How to find your location's temperatures (AccuWeather, etc.)
3. **Yarn Selection** — Choosing colours, yarn weight, fibre content
4. **Colour-Temperature Key / Chart** — The critical mapping table
5. **Pattern Instructions** — The actual stitch pattern (often very simple)
6. **Staying on Track** — Tips for managing a year-long project
7. **Finishing** — Weaving in ends, blocking

### Colour-Temperature Key Format

The key is typically presented as a table:

| Colour | Temperature Range |
|--------|------------------|
| Dark Green | −40°C to −11°C (−40°F to 13°F) |
| Light Green | −10°C to −5°C (14°F to 23°F) |
| Light Blue | −4°C to 0°C (24°F to 32°F) |
| Medium Blue | 1°C to 5°C (34°F to 43°F) |
| Dark Blue | 6°C to 10°C (44°F to 53°F) |
| Burgundy | 11°C to 15°C (54°F to 63°F) |
| Dark Pink | 16°C to 21°C (64°F to 73°F) |
| Light Pink | 22°C to 28°C (74°F to 83°F) |
| Beige | 29°C+ (84°F+) |

- [Gabrielle Vézina: Temperature Blanket Pattern](https://gabriellevezina.com/knitting-tutorials/miscellaneous/how-to-knit-a-temperature-blanket-or-scarf-tutorial-and-free-knitting-pattern/) — Full example with calculation method

### How Instructions Are Written for Temperature Blankets

Because the stitch pattern repeats for 365+ rows, the instructions are extremely concise:

**Example (Gabrielle Vézina's ribbed temperature blanket):**
```
Blanket row: (K1, p1) 6 times, (k2, p2) to last 12 sts, (k1, p1) 6 times.
Work one blanket row every day for a year, using the color corresponding to this day's temperature.
```

Key conventions:
- The **same row instruction** is repeated for every day
- The **colour changes daily** based on the temperature key
- Setup rows and ending rows are worked in the first (coldest) colour
- The pattern specifies **one row per day** (knitting) or **one row per day** (crochet)
- Stitch counts are given for the cast-on but not repeated per row

- [Gabrielle Vézina: Temperature Blanket Pattern](https://gabriellevezina.com/knitting-tutorials/miscellaneous/how-to-knit-a-temperature-blanket-or-scarf-tutorial-and-free-knitting-pattern/) — Shows the concise "one row" pattern format
- [Handy Little Me: 20 Temperature Blanket Patterns](https://www.handylittleme.com/temperature-blankets/) — Notes that "most people follow a temperature blanket chart that tells them which colors to use"
- [Sarah Maker: How to Make a Temperature Blanket](https://sarahmaker.com/temperature-blanket/) — Roundup of 17 free patterns showing various approaches

### Common Stitch Choices for Temperature Blankets

Temperature blanket patterns typically use simple, reversible stitches:
- **Garter stitch** (knitting) — Simplest, every row knit
- **Stockinette stitch** (knitting) — Alternating knit/purl rows
- **2×2 ribbing** (knitting) — Reversible, textured
- **Single crochet** (crochet) — Basic, dense fabric
- **Moss/Linen stitch** (both) — Textured but simple repeat
- **C2C (corner to corner)** (crochet) — Square-based construction
- **Granny squares** (crochet) — Classic modular approach

- [Noble Knits: Temperature Blanket Guide](https://blog.nobleknits.com/blog/how-to-knit-crochet-temperature-blankets) — Recommends "simple stitches" for daily work
- [Oombawka Design: Temperature Blankets](https://oombawkadesigncrochet.com/temperature-blankets-crochet-patterns-color-charts-and-tracking-sheets/) — Notes that "if you crochet 365 days worth of temperatures, that means your blanket will be 365 rows long"

### Temperature Blanket Specific Advice from Designers

- Use **round numbers** for temperature ranges (5° or 10° increments) — easier to remember
- Choose yarns that are **still available for purchase** — you may need to buy more mid-project
- Have at least **200g (300g safer)** of each colour in worsted weight
- Consider **weekly aggregation** if daily is too much (52 rows instead of 365)
- **Carry yarn up the side** for 1-2 row colour sequences; cut and rejoin for wider stripes
- Leave a **6-inch tail** for weaving in ends

- [Gabrielle Vézina: Afterthoughts](https://gabriellevezina.com/knitting-tutorials/miscellaneous/how-to-knit-a-temperature-blanket-or-scarf-tutorial-and-free-knitting-pattern/) — Practical advice from completing a temperature blanket

## 10. Implications for TempStitch

Based on this research, here are concrete recommendations for how TempStitch's generated patterns should be structured and worded:

### Pattern Structure

TempStitch patterns should follow the standard section order, adapted for the unique nature of temperature projects:

1. **Title & Overview** — Pattern name, location, year, skill level (Beginner)
2. **Colour-Temperature Key** — A prominent table mapping temperature ranges to colour names. This is the most critical section and should appear early, before instructions.
3. **Materials** — Yarn weight, hook/needle size, notions. Include total yardage estimate per colour.
4. **Gauge/Tension** — State clearly. For temperature blankets this is less critical than for garments, but still useful for size estimation.
5. **Abbreviations** — Use US terms as the default (wider international audience), but clearly state "Written in US crochet terms" or "Written in US knitting terms". Include the UK equivalents in parentheses or a side note for international users.
6. **Finished Dimensions** — Estimated width and projected length based on stitch count and row count.
7. **Instructions** — Concise row-by-row instructions. For temperature blankets, this is typically ONE row repeated for the entire project.
8. **Colour Change Notes** — Explain the technique for joining new colours cleanly.
9. **Finishing** — Weaving in ends, blocking.

### Terminology Decisions

- **Default to US terms** for crochet (industry standard for online patterns)
- **Always declare the terminology system** at the top of the pattern
- **Include both US and UK names** in the abbreviation list for accessibility
- Use the Craft Yarn Council standard abbreviation list as the baseline
- For knitting, use standard abbreviations: k, p, CO, BO, yo, k2tog, etc.

### Row Instructions

- Use the standard format: **Row 1 (RS):** followed by abbreviated instructions
- Include **stitch counts** at the end of each row (e.g., "50 sts")
- For temperature blanket "daily rows," provide ONE master row instruction with a note: "Repeat this row for each day, using the colour from your temperature key."
- Use **bold** for row headers
- Use **asterisks** for repeat sections

### Colour Instructions

- Present the colour key as a **prominent table** with colour names, swatches (if possible), and temperature ranges
- Include both **°C and °F** for international users
- Use the format: "Colour Name: X°C to Y°C (X°F to Y°F)"
- In the row instructions, state: "With the colour corresponding to today's temperature, work the blanket row."
- Provide a **plain-English tip** on how to join a new colour at the start of a row

### Beginner-Friendly Adjustments

- Write **full stitch names alongside abbreviations** on first use: "knit (k)"
- Include **inline tips** in italics: _"To change colours, complete the last stitch of the previous row with the new colour."_
- Keep the stitch pattern **as simple as possible** (garter stitch, single crochet, or basic ribbing)
- Provide **stitch counts** so beginners can verify their work
- Include a note about **what to do if you fall behind** (check historical temperatures, batch rows)

### Gauge/Tension

- State gauge clearly even though it's less critical for blankets
- Use the format: "X sts × Y rows = 4 inches (10 cm) in [stitch pattern]"
- Note: "Gauge is not critical for this project, but matching it will give you the estimated finished dimensions."

### Digital Pattern Considerations

- The colour-temperature key should be **interactive or easily scannable** — users will reference it daily
- Consider providing a **downloadable/printable colour chart**
- Include a **tracking mechanism** suggestion (notebook, app, spreadsheet)
- Use **clear section headers** that can be navigated to quickly
- Avoid dense paragraphs — use bullet points and tables for scannability
